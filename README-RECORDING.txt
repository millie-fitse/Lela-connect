HEY. — LOCAL VIDEO RECORDING

Recording is a browser-only feature. Hey. does not upload or store recordings on the server.

HOW IT WORKS
- Recording is never automatic.
- The user taps the new Record button while matched.
- The other participant receives a recording consent request.
- Recording starts only after the other participant allows it.
- The recording contains the Hey. video encounter (Stranger + You), not browser/desktop chrome.
- Local microphone and remote audio are included when the browser permits it.
- Stopping the recording automatically saves a WebM file to the user's device.
- Pressing Next, Stop, or losing the stranger ends the active recording locally.

SERVER ROLE
The server only relays two small signaling messages: record-request and record-response. No recording bytes are sent to the server.

BROWSER SUPPORT
Modern Chrome, Edge, Firefox, and Safari are recommended. WebM/MediaRecorder support can vary by browser.
